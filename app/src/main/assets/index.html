Webhook • إعداد جاهز

انسخ رسالة JSON التالية وضعها في خانة Message عند إنشاء تنبيه في TradingView. لاستقبالها آلياً داخل SONAR يجب نشر مستقبل Webhook على عنوان HTTPS عام؛ عنوان الهاتف المحلي 127.0.0.1 لا يمكن لـ TradingView الوصول إليه مباشرة.

مهم: TradingView يرسل Webhook إلى عناوين عامة عبر المنفذين 80 أو 443 فقط، ويتطلب تفعيل المصادقة الثنائية للحساب. هذا الملف يجهز صيغة التنبيه، لكنه لا يستقبل Webhook بنفسه دون خادم HTTPS وسيط.
حدود الربط: مخطط TradingView رسمي ومضمّن. TradingView Widgets تعرض بيانات الرسوم المضمنة ولا تمنح SONAR API للوصول إلى بياناتها الداخلية أو Pine Script الخاص. بيانات السونار والأسعار التشغيلية تُجلب من Binance Spot/Futures، مع بقاء اختيار مصدر TradingView للرسوم مستقلاً.
